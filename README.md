# Tampisaw website (template)

Static site. No build step. Open index.html to preview.

## Change content
Edit **data.js** only: business name, contact, packages, prices, add-ons, stays, FAQ.
Put photos in **images/** and match the file names in data.js
(hero.jpg, island-day.jpg, floating.jpg, sunset.jpg, overnight.jpg, g1.jpg to g6.jpg).
Missing photos show a soft colour block, so nothing breaks.

## Set up booking messages (data.js, contact section)
- phone: number for the "Send as text" button
- whatsapp: number with country code, no + (e.g. 639171234567)
- messengerPage: the part after facebook.com/ (the Messenger button opens m.me/<page>)

## Publish free
Upload this folder to Netlify (drag and drop) or GitHub Pages. Connect a custom domain there.
